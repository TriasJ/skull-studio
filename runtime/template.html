Editor help

Workflow

1 · Pick an element (canvas click or left list; ■ Background edits the slide background's idle animation).
2 · Tune Entrance (how it appears), Idle (continuous motion), Parallax (mouse depth) in the right panel. Replay previews the slide.
3 · For organic motion: Enable mesh deform, place pins, switch to Pose mode, drag pins at different playhead times to set keyframes.
4 · Studio: edits autosave to the project. Single-file: Export overrides.json, then rebuild.

Rig (mesh / 2D bones)

Fastest start: pick a Quick motion preset (Breathe, Sway, Float, Pendulum, Wave) in the Mesh deform panel — it builds the pins and a looping animation you can then refine. Or build by hand:
① Setup pinsclick the image to add a pin, drag to place it. Gold pins drive motion, gray pins anchor (hold still). Shift+click a pin then click = child bone (chain); Alt+drag = rotate; Delete removes a pin.
② Animatemove the playhead on the timeline, then drag a pin to record a keyframe there. The first keyframe auto-adds rest keys at 0s and the end so the motion loops home. ▶ Play previews.
timelinedrag the ruler to scrub; drag a diamond sideways to re-time it; right-click a diamond (or select it and Delete key) to remove it.

3D models

Add a shapeStudio 3D menu: pick a colour, then click plane / cube / sphere / cylinder / cone / torus. It drops on the current slide and renders live.
ImportedPowerPoint Insert → 3D Models come in automatically; baked glTF animations play. Tune clip / loop / auto-rotate / camera FOV in the inspector.
Move / Orbit / Pan / Zoomselect a 3D model to get the floating 3D bar (bottom): Move edits its box; Orbit / Pan drag the camera; − / + (or scroll on the model) zoom; Reset recentres. The interactive setting carries into the exported HTML viewer.
Exportimported models round-trip to PowerPoint as live 3D; added primitives bake to a picture in PPTX (PowerPoint only shows 3D it imported itself) but stay interactive in the HTML export.

Saving vs exporting - what's what

Save Ctrl+Swrites your edits into the project file (work/manifest.json). Studio autosaves ~1s after every change; this is your working document, not a deliverable. (The single-file editor saves to browser localStorage instead.)
Previewbuilds the final presentation and opens it in a new tab - exactly what your audience will see (no editor, no gizmos).
Export HTMLproduces the deliverables in dist/: presentation.html (viewer-only, share this), editor.html (this editor bundled with the deck), or presentation_with_editor.html (one file that presents and edits).
Export manifest.jsondownloads the whole project document (every slide, element, animation, rig). Use as a backup, for hand-editing, or to restore by copying over work/manifest.json.
Export overrides.jsondownloads only your edits (per-element diffs). Made for the single-file editor workflow: edit editor.html anywhere, export, then bake with node scripts/build.mjs --apply overrides.json. In Studio you rarely need it - Save already persists everything.

Studio extras

All Studio actions live in the top-left menu bar (File / Preprocess / Tools / 3D / Options / Help); the top controller keeps just the slide nav. Drag a selected element to move its detection box, gold corner to resize, then Re-crop & reload. ▭ Box/⬡ Poly draw new elements (editable immediately; pixels appear after re-crop). Polygon: click vertices; click the first (ringed) node, Enter or double-click to close; Backspace or right-click undoes the last point. Mask areas (+/− Box/Poly) boolean-edit the selected element's shape. OCR text reads the element's text from the slide image.
